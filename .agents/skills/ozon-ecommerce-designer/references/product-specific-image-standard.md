# 商品专属 Ozon 图片标准

## 核心判断

一张图是否像成熟电商图，不由固定模板、装饰数量或单纯高对比决定，而由
商品理解、购买理由、真实场景、信息层级和视觉执行共同决定。先回答“这个
商品为什么值得买”，再决定画面；不得先选模板再填文字。

**照片级硬要求（2026-08-15）**：每张出图都必须像卖家实拍的商品照片——真实
材质纹理、镜头景深、环境光、柔和阴影、可信反光。不得出现 3D 渲染、CGI、
矢量或平面插画观感；产品主体必须来自本商品真实参考图（edit 保留真实产品
照片、compose 只拼真实照片元素），不得凭空重建商品再冒充摄影。

P900002 已验收图组只定义最低商业完成度：商品必须足够大、俄文层级必须一眼
读懂、对比度必须抓眼球、信息必须直接回答购买问题。不得继承它的冰箱场景、
绿色、左右布局、图标、文案或任何商品事实。

## 主图三秒信息

主图必须让俄罗斯买家在三秒内理解：

1. 这是什么商品；
2. 用于什么场景或解决什么问题；
3. 当前 SKU 的容量、尺寸、颜色或配置；
4. 至少一个由真实结构或资料支持的购买理由。

主图使用 3:4，商品通常占画面宽度约 45%–65%、高度约 50%–70%，但由
商品形状和场景决定。标题通常不超过两行，SKU 标识与商品绑定，不能遮挡
关键结构。这里的比例是判断基准，不是固定坐标模板。

“通常不超过两行”不等于禁止清楚标题。标题可以醒目，但必须像 Ozon 商品信息
模块，而不是海报口号或大面积黑黄底板。商品仍是视觉中心，标题不能压住商品，
也不能让所有商品机械套同一种标题版式。

商品/真实商品照片区域必须是最大视觉区域。文字、徽标、图标和说明模块只做
辅助，不得比商品更抢眼。每段俄文必须和背景形成高对比：深色或品类色底板配
浅色字，或者浅色底板配深色字；禁止浅色字压在浅色背景、暗色字压在暗背景、
或靠模糊场景硬撑可读性。

文字模块必须像成熟商品信息设计，而不是临时字幕。禁止默认使用左上角竖线 +
三行小标题、角落孤立标题、没有承载关系的细小规格堆、单色阴影背景上的白字、
以及与商品主体没有连线/尺度/结构/场景关系的文字块。每个文字模块必须选择一种
和商品证明点绑定的形式：尺寸线、结构 callout、SKU 规格标签、步骤编号、紧凑
信息组、自然留白标题组或与产品边缘/阴影/台面透视对齐的说明。文字不一定多，
但必须有层级、有留白、有对齐、有对比，并且看起来是为这张图专门设计的。

## 高价值感来源

- 使用与商品用途一致的真实场景、前景、背景和自然景深。
- 让商品成为绝对视觉中心，边缘、材质、结构和配件清楚可信。
- 用商品或品类自然产生的颜色建立体系；控制在 3–5 个主要颜色。
- 通过留白、字体层级、光线和材质形成对比，不依赖发光、渐变或后台卡片。
- 卖点必须具体到本商品的结构、使用动作或购买风险，拒绝“优质、方便、
  高性价比”等空话。
- 图标只解释已验证卖点，风格必须与商品和画面一致。

## 每张图必须重新做的创意决策

为每个图位分别决定并记录：商业目的、买家问题、场景、构图、商品占比和
位置、背景、色彩、光线、文字层级、每段文字的准确位置和表现方式、图标
逻辑、自然留白、价值感来源以及与同组其他图片的差异。共享详情图必须形成
购买决策顺序，不能只换背景或标题。

这些决策不能只散落在字段中。设计师必须把它们汇总为每个图位的一条完整最终
提示词：明确商业目的、真实参考、场景与证明关系、3:4 构图、镜头、商品位置与
占比、商品专属高对比配色、光线与材质、价值感来源、全部准确俄文、文字层级与
位置、必须保持项和禁止项。整套 N+8 的完整提示词全部完成后才能开始生图；
生图器只执行，不再补设计、不改文案、不把提示词降级成空洞场景图。若设计草稿
里出现俄文文案缺失、overlay 顺序不一致、主图模块不完整、构图描述太弱等
提示词层面问题，由电商设计师在进入生图前直接修正完整提示词，不把它变成
商品任务需要处理。

视觉总监只在生图前生效：负责提高分镜、场景、镜头、商品占比、材质价值感、
俄文层级、配色和提示词完整度。生图后只检查事实和上传安全，不做主观审美
硬拦截。只要商品、SKU、颜色、结构、比例、配件数量和准确俄文没有变，背景、
留白、文字位置、信息芯片形状、整体风格和“好不好看”只能作为质量记录或下次
重新设计参考，不能自动删除已生成图片、重复付费生图或停止商品。

视觉总监可以硬拦的范围仅限：错商品、错 SKU、颜色/结构/比例被改、虚构配件
或功能、图片数量缺失、俄文缺失/乱码/不可读、出现中文/供应商水印/浏览器界面、
引用了非当前商品图片，或 Ozon 图片上传会失败的问题。

视觉总监必须先设计销售故事线，再写每张图提示词。销售故事线不是八张海报、
不是卖点列表，也不是换背景贴同一套文字。它要把 SKU 主图和 8 张详情图组织成
一个购买决策过程：先让买家认出商品，再理解核心用途/欲望，再看结构或材质证明，
再确认尺寸/参数或使用步骤，再做 SKU/款式选择，再看到真实使用或比例场景，
再 close-up 检查关键细节，必要时给出基于商品事实的购买提醒。具体顺序和角色
可以按商品调整；不得强制每个商品都有人物图、固定第 8 张提醒图或固定生活方式
场景，但每张详情图必须回答不同购买问题，并推动这个故事继续往下走。

禁止“海报贴字”不是禁止大字，也不是禁止信息图。合格图可以有醒目标题、尺寸线、
步骤条、颜色/规格标签和卖点说明，前提是这些文字在解释真实商品、真实尺寸/步骤、
SKU 差异、结构证明或使用场景。真正禁止的是“通用背景 + 无关标题/卖点”，也就是
文字和商品证明没有关系。最终提示词必须描述一张完整电商摄影图或信息图，商品、场景、
证明点和俄文文字属于同一个画面逻辑。如果草稿看起来只是“背景 + 标题 + 卖点”，
或把文字去掉后图片逻辑没有变化，电商设计师必须在进入 image_plan 前改写成具体买家
场景、尺寸/步骤图或结构证明构图。

合格信息图可以参考三类组织方式：三秒认知图（大商品主体 + 核心品名/颜色/规格）、
尺寸证明图（展开/收纳状态、长宽高线条或明确参数）、步骤教学图（真实操作的 1/2/3
过程）。这些只是信息组织方法，不是固定背景、配色、左右版式或类目模板，也不得继承
示例图中的商品事实。

同一商品的 SKU 主图可以保持统一视觉语言，但每张必须绑定本 SKU 的真实
图片、规格和文字。共享详情图只使用所有 SKU 共有的事实。

## 参考图中可继承的原则

- 3:4 竖版；在自然留白、侧栏或场景中建立清楚的商品名称与用途层级，
  不固定为顶部大标题。
- 商品大而清晰，真实使用场景承担价值证明。
- 图片区域优先，文字模块紧凑并有高对比底板。
- 一侧用少量图标和短文案解释具体结构卖点。
- SKU 容量或规格作为克制的商品信息，不固定为徽章或色块锚点。
- 米白、深色文字、品类主色和自然材质形成高对比但不廉价。

不得机械复制参考图的绿色、厨房场景、左右布局、图标或商品事实。不同商品
必须从自己的用途、材质、结构和目标买家重新得出视觉答案。

## 禁止项

- 固定标题框、固定容量框、固定三卡卖点栏在不同商品间重复使用；
- 先生成无商品逻辑的通用背景，再把商品名和卖点塞进预留框；
- 默认左上角竖线标题块、角落孤立小字、像临时字幕一样的规格堆；
- 用技术预览、无字氛围图或白底抠图冒充成品电商图；
- 用 3D 渲染、CGI、矢量或平面插画风格冒充卖家实拍照片；
- 给磁吸支架等真实结构发明夹臂、支架等参考图中不存在的结构件；
- 商品事实未分析完成就开始写提示词或生图；
- 设计师没有给出逐图艺术指导时由排版器自行选择版式、颜色或图标；
- 用其他商品、历史输出或测试附件补当前商品的事实。

## 执行边界

电商设计师负责整套创意决策和完整最终提示词；图片编辑器在一次调用中忠实
生成场景与准确俄文排版。`overlay_plan` 是同一次生图调用的排版指令，不存在
后置叠字或动态排版补救。执行器不得拥有默认商业版式。联网模型暂不可用时
暂停；普通提示词缺陷则由电商设计师自动补齐、重写或规范化后继续。
