# Ozon 关键词增长框架

市场结论只允许使用 Seefar 关键词级市场数据（关键词挖掘页/导出）。单店 Seller
API 数据不能证明市场增长，只能作为补充验证。Seefar 没有类目 API，本框架只
针对关键词维度。

## 1. 增长门槛（Growth = 搜索需求是否上升）

增长必须同时看**月搜热度（绝对量）**与**月搜增长（增长率）**，禁止只按
增长率排名。

| 信号 | 门槛 | 含义 |
|---|---|---|
| 月搜增长 | > 10% | 候选证据 |
| 月搜增长 | > 20% | 优先证据 |
| 月搜热度（绝对量） | 不低于关键词池中位数 × 5% | 排除「从 1 到 2」的低基数尖峰 |

低基数尖峰判定：`月搜热度 < 池中位数 × 5%` 且增长率高，视为可疑，进入排除项。

## 2. 机会评分（Opportunity = 增长是否可重复、可进入）

机会分 = 需求动量 + 竞争 + 集中度 + 稳定性 + 运营风险（每项 0–20，满分 100）。

| 维度 | 评分依据 | 说明 |
|---|---|---|
| 需求动量 (0–20) | 月搜增长 + 月搜热度组合 | 双高给满，单高减半 |
| 竞争 (0–20) | 竞品数 / 竞对数 / 广告竞品数 | 竞品越多越拥挤，分越低 |
| 集中度 (0–20) | `conversion_concentration_percent`（转化集中度） | 转化越集中在少数商品，越难进入 |
| 稳定性 (0–20) | 多周期一致、非单点尖峰 | 单周期导出无法证明，默认中性 |
| 运营风险 (0–20) | `return_cancel_rate_percent`（退货取消率） | 退货取消率越高，履约风险越大 |

转化集中度（不是前五卖家份额）：
- **偏高** → 谨慎，集中度维度记低分；
- **偏低** 且其他信号健康 → 优先。

## 3. 排除项（直接出榜）

- **低基数尖峰**：月搜热度过低、增长率虚高；
- **垄断/高集中**：转化集中度过高且持续；
- **供给拥挤**：竞品数 / 竞对数 / 广告竞品数已很高；
- **高退货**：退货取消率显著高于池内中位。

排除项单独列表，附排除原因与「什么条件下可重新进入」。

## 4. 价格约束（不做利润评分）

关键词阶段**不做利润评分**，只输出：
- 目标价格区间（`average_price_rub`）；
- 成本约束（采购 + 头程 + 平台佣金 + 履约）。

## 5. 置信度与下一步

每个方向必须给出：
- **证据**：来自哪份 Seefar 关键词导出、哪个窗口；
- **置信度**：高/中/低（数据完整 + 多周期一致 → 高）；
- **假增长风险**：低基数 / 季节 / 单一来源；
- **下一步验证**：该关键词下深挖商品，或补数据缺口。
