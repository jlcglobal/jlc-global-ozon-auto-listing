# AI Factory 工作台视觉契约（2026-07-14）

## 范围

本契约覆盖当前真实工作台的全部现有页面。只重构界面层，不新增业务功能，不改变接口、数据结构、状态机、权限、安全确认、上传条件或库存禁用规则。

## 视觉基准

- 产品气质：未来感、克制、明亮、适合长时间生产操作。
- 背景：冷灰画布；主体面板使用白色和极浅紫灰。
- 主色：紫色用于导航、选中态和主要进度；绿色只表示通过或安全状态；红色只表示风险和破坏性操作。
- 圆角：应用外壳约 26px，主面板 18–22px，按钮和输入框 10–14px。
- 阴影：只用于应用外壳、浮层和当前聚焦对象，避免每张卡片都有重阴影。
- 图标：统一使用本地 Phosphor 图标字体，不使用表情、文字符号、手绘 SVG 或 CSS 图形。
- 动效：页面和图片切换使用 160–260ms 的轻量进入与状态过渡；尊重 `prefers-reduced-motion`。

## 页面骨架

- 左侧：72px 紫色图标轨道，承载全部现有一级页面。
- 顶部：页面标题、全局搜索、刷新/通知、手动检查状态和负责人信息。
- 普通页面：标题/筛选区 + 卡片、表格或列表内容区。
- 商品预览：左侧生产流程、中间真实图片工作区、右侧资料面板、底部固定命令台。
- 移动端：一级导航抽屉化，商品图片与资料面板纵向滚动，主操作持续可达。

## 业务边界

- 不在视觉层推断或补写未知商品事实。
- 不改变“运行任务”、上传、彻底删除、图片删除、店铺验证等动作原有确认和后端约束。
- 不新增库存字段，不调用库存接口。
- 未知值仍由现有数据规则显示；结构化数值必须先格式化，禁止向用户显示 `[object Object]`。
