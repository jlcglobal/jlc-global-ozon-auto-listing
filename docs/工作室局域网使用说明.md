# 工作室局域网使用说明

## 主电脑

1. 在主 Mac 双击桌面的`AI Factory.app`，或项目根目录的`启动工作室工作台.command`。
2. 主电脑负责店铺凭证、连接测试、自动模式和系统设置，不需要再创建成员访问码。
3. 保持主 Mac 开机并连接同一局域网；启动成功后可以关闭终端窗口，工作台会继续在后台运行，异常退出时会自动重新启动。
4. macOS 第一次询问是否允许接收网络连接时，选择允许。
5. 重复双击不会启动第二个服务；如果工作台已经运行，只会重新打开浏览器。

## 员工电脑

1. 解压 `release/1688商品采集插件-0.4.11.zip`。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 打开开发人员模式，选择“加载解压缩的扩展”，选择解压后的插件目录。
4. 打开插件中的“主电脑连接”。
5. 只填写主 Mac 的局域网工作台地址，点击“保存并连接”；电脑会自动识别，不需要访问码。
6. 显示“已连接共享工作台（无需访问码）”后即可采集1688商品。
7. 点击“打开共享工作台”会进入共享工作台。

## 任务规则

- 可以在商品审核台只运行一个商品。
- 可以在采集箱勾选多个商品创建批次。
- 有任务正在运行时，新任务自动排队，不会覆盖当前任务。
- 同一个商品被多人重复点击时，只保留原任务，不会重复上传。
- 所有工作室电脑看到同一套商品、批次、预览、错误通知和进度，可以接着处理另一台电脑采集的商品。
- 系统自动记录是哪台电脑执行了本地写操作，不记录请求正文或店铺密钥。
- 只有主电脑可以管理店铺、凭证、全局模式和系统设置；其他电脑不会因为免码获得这些权限。
- 工作台仍只允许配置的局域网地址和可信页面/插件访问，普通外部网页不能调用。
- 系统不提交库存字段，不调用库存接口。

## 地址变化

如果路由器重新分配了主 Mac 地址，员工插件需要填写新的地址。建议以后在路由器中为主 Mac 固定局域网地址。
