# 工作室局域网使用说明

## 主电脑

1. 负责人在主 Mac 的项目根目录启动工作台服务：

   ```bash
   python3 -m uvicorn app:app --app-dir collector/local-ingest --host 0.0.0.0 --port 8765
   ```

2. 在“系统设置”中启用工作室局域网访问，并为每位成员创建独立访问码。
3. 保持主 Mac 开机并连接同一局域网，不要关闭服务终端。
4. macOS 第一次询问是否允许接收网络连接时，选择允许。
5. 当前尚未提供一键启动器；不要使用文档外的旧启动文件。

## 员工电脑

1. 解压 `release/1688商品采集插件-0.4.6.zip`。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 打开开发人员模式，选择“加载解压缩的扩展”，选择解压后的插件目录。
4. 打开插件中的“主电脑连接”。
5. 填写主 Mac 的局域网工作台地址和自己的成员访问码，点击“保存并连接”。
6. 显示“已连接主电脑”后即可采集1688商品。
7. 点击“打开共享工作台”会进入共享工作台。

## 任务规则

- 可以在商品审核台只运行一个商品。
- 可以在采集箱勾选多个商品创建批次。
- 有任务正在运行时，新任务自动排队，不会覆盖当前任务。
- 同一个商品被多人重复点击时，只保留原任务，不会重复上传。
- 每位成员只看到、修改、运行和上传自己采集的商品；不会显示其他成员商品。
- 商品批次、错误通知和Ozon发布状态也只对商品所属成员显示。
- 负责人可以管理成员、店铺和全局设置，但不能查看其他成员商品。
- 系统不提交库存字段，不调用库存接口。

## 地址变化

如果路由器重新分配了主 Mac 地址，员工插件需要填写新的地址。建议以后在路由器中为主 Mac 固定局域网地址。
