# 工作室局域网使用说明

## 主电脑

1. 主 Mac 双击项目根目录的 `启动工作室工作台.command`。
2. 启动窗口会显示工作台地址和工作室访问码。
3. 保持主 Mac 开机、联网，不要关闭启动窗口。
4. 服务运行期间会阻止主 Mac 自动休眠。
5. macOS 第一次询问是否允许接收网络连接时，选择允许。

## 员工电脑

1. 解压 `release/1688商品采集插件-0.4.6.zip`。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`。
3. 打开开发人员模式，选择“加载解压缩的扩展”，选择解压后的插件目录。
4. 打开插件中的“主电脑连接”。
5. 填写启动窗口显示的工作台地址和工作室访问码，点击“保存并连接”。
6. 显示“已连接主电脑”后即可采集1688商品。
7. 点击“打开共享工作台”会进入共享工作台。

## 任务规则

- 可以在商品审核台只运行一个商品。
- 可以在采集箱勾选多个商品创建批次。
- 有任务正在运行时，新任务自动排队，不会覆盖当前任务。
- 同一个商品被多人重复点击时，只保留原任务，不会重复上传。
- 所有电脑看到相同的商品、批次、错误和Ozon状态。
- 系统不提交库存字段，不调用库存接口。

## 地址变化

如果路由器重新分配了主 Mac 地址，员工插件需要填写新的地址。建议以后在路由器中为主 Mac 固定局域网地址。
